# 0　总论：优秀论文是一条完整证据链

37篇论文反复出现的最稳定结构，不是“模型越多越优秀”，而是：

> **准确理解题目 → 建立统一机制 → 选择匹配算法 → 给出可执行结果 → 建立可信证据 → 用评委能快速验证的方式呈现。**

六个维度不是彼此独立的装饰项，而是顺序依赖：

1. **选题理解**决定研究对象、目标、约束和小问关系；
2. **模型设计**把现实关系转化为状态、变量、公式与模型接口；
3. **求解与算法**针对模型结构完成计算；
4. **结果质量**证明答案完整、可行、合理且在一定范围内稳定；
5. **论文表达**把机制、答案和证据组织成可阅读文本与图表；
6. **竞赛意识**确保评委在有限时间内发现完成度、亮点、可信度和交付物。

如果前一环节存在缺陷，后一环节通常无法补救：题目理解错误，复杂算法也只会精确地求错问题；模型接口断裂，再精美的图也不能形成完整论证；结果没有验证，再强的摘要措辞也只是包装。

## 0.1 六维总表

| 维度 | 核心问题 | 强论文标准 | 典型反例信号 | 代表证据 |
|---|---|---|---|---|
| 选题理解 | 到底在研究谁、求什么、受什么限制 | 对象、目标、约束、指标、小问关系明确 | 层级混淆、漏问、目标口径变化 | A196单弹到多机递进；D037水流到逃生 |
| 模型设计 | 变量为何这样连接 | 基础模型明确，改进针对假设失效，模型有接口 | 为复杂而复杂、模型并列无输入输出 | A165微元机理；B060双光束到多光束 |
| 求解算法 | 如何稳定地算出来 | 算法与结构匹配，有参数、停止、约束处理 | 只写算法名、无停止条件、随机一次 | A163二分；A242粗搜—精搜；B060直接法+Newton |
| 结果质量 | 为什么相信这个答案 | 直接回答、约束核验、对照、误差、敏感性 | 只给最优值、自称稳定、无基线 | B060双方法一致；B159枚举核对 |
| 论文表达 | 如何让证据清楚可读 | 主线清楚，公式回引，图表服务论证 | 软件默认图混杂、公式堆叠、大表挤正文 | A165图6；E010第10页对比；E030第10页标定 |
| 竞赛意识 | 评委能否快速发现价值 | 摘要逐问、亮点显性、结果文件规范、局限诚实 | 算法包装、虚假精度、单位错误、夸大全局最优 | C023创新三点与局限；A242结果文件；A053单位风险 |

# 第一部分　六个维度的核心特征、标准与实例

# 1　选题理解

## 1.1 核心特征一：对象—目标—约束—指标必须闭合

### 判断标准

一篇论文应能用一张表回答：

| 项目 | 必须明确的内容 |
|---|---|
| 研究对象 | 个体、系统、空间、时间和层级是什么 |
| 决策/待求量 | 哪些量需要计算，哪些量可被控制 |
| 目标 | 最大化、最小化、预测、分类、识别还是评价 |
| 硬约束 | 不满足即不可执行的条件 |
| 评价指标 | 用什么量判断答案好坏 |
| 交付物 | 表格、路线、参数、文件、分类结果或建议 |

只有目标函数而没有对象层级，不算理解完整；只列题面数据而没有决策量，也不算完成数学抽象。

### 论文证据

- **C050**：PDF第1页摘要和问题分析明确区分“蔬菜品类”和“单品”两个层级；问题二做品类级周计划，问题三做单品级日计划，并纳入在售数量27—33和每个单品最小陈列量2.5 kg。该论文值得模仿的不是模型数量，而是对象层级没有混用。
- **D033**：第1页摘要和概率章节始终围绕“潜艇空间位置—深弹引爆点—毁伤区域—命中事件”展开，三问只增加深度误差和多弹，不改变命中事件定义。
- **D037**：第1页摘要把巷道、突水状态、人员位置和逃生路线区分为不同对象；水流到达时间是状态量，逃生路线是决策输出。

## 1.2 核心特征二：先判断小问是递进、分层还是并列

### 三类关系

1. **线性递进**：前一问输出直接进入后一问。  
   代表：A196单弹→多弹→多机→多目标；B060双光束→色散修正→多光束；2024 A题位置→碰撞→螺距→调头→速度。
2. **层级下钻**：从总体、品类或群体进入单品、个体或局部。  
   代表：C050品类→单品；C023群体关系→BMI分组→个体时点。
3. **并列共享状态**：小问不强递进，但共享同一数据和系统口径。  
   代表：E010/E061/E218的流量估计、信号控制、停车需求和政策评价。

### 判断标准

- 前一问的输出是否在后一问中出现；
- 后一问是增加现实条件，还是换了研究对象；
- 并列小问是否保持时间、空间、样本和指标口径一致；
- 总流程图能否表示数据和状态如何流动。

### 论文证据

- **A196**：第1页摘要分别报告单弹4.5873 s、单机多弹6.9359 s、多机单目标11.1259 s、多机多目标21.0770 s；所有小问共享“有效遮蔽时间区间并集”。这是最典型的统一指标递进。
- **B060**：第1页先给双光束直接法和Newton反演的厚度，再在残差显示基础模型不足时使用多光束模型；新模型由旧模型失效触发，而不是任意替换。
- **E010**：PDF第10页通过聚类确定时段，后续流量、信号和停车模型共享时段标签。四问虽并列，但有统一状态接口。

## 1.3 核心特征三：题目边界要写成“不能混淆什么”

优秀问题分析不只写“难点”，还明确错误边界：

- 2023 B题：不能混淆不同重叠率口径，不能以平均水深代替变深地形；
- 2023 C题：不能把品类和单品混在同一层，不能把相关性直接解释为价格因果；
- 2024 A题：不能把有限宽度板凳当质点；
- 2024 B题：不能把抽样检验与后续生产策略割裂，不能遗漏返工循环；
- 2025 C题：同一孕妇重复检测记录不能视为独立样本；
- 2025 D题：不能先静态求最短路，再忽略路径随淹水时间失效。

### 可直接模仿：问题分析五句法

```markdown
本题研究对象为【对象与层级】，需确定【待求量/决策量】。
核心目标是【目标】，评价指标为【指标及方向】。
方案必须满足【硬约束】。
各小问关系为【递进/分层/并列共享状态】，其中问题X输出的【变量】进入问题Y。
本题最容易出现的理解偏差是【边界问题】，因此本文统一采用【口径】。
```

# 2　模型设计

## 2.1 核心特征一：基础模型先抓主要机制

优秀论文通常先建立低维、可检查的基础关系，再增加现实因素：

- A165：反射与微元有效面积；
- B311：条带覆盖和重叠递推；
- D033：单枚深弹命中事件；
- A196：单烟幕视线遮蔽；
- B060/B157：双光束光程差；
- C023：群体固定效应和个体随机效应；
- D037：巷道图与流量守恒。

### 判断标准

- 基础模型能否在少量假设下独立运行；
- 每个变量是否具有现实含义；
- 公式关系来自物理定律、概率定义、统计结构或业务规则；
- 基础模型是否提供后续模型共享的状态或参数。

## 2.2 核心特征二：改进模型必须针对明确失效条件

### 优秀递进实例

- **B060/B157**：双光束模型是基础；折射率色散是必要修正；残差和频率特征显示多光束效应时，再使用Airy模型。改进由基础假设失效触发。
- **C038**：确定性多年种植规划→随机销量、产量、价格和成本→CVaR尾部风险→替代互补关系。每次增加一个现实因素。
- **C023**：普通群体关系→重复测量混合效应→BMI分组风险→异常判定。统计结构来自数据生成过程。
- **D037**：静态巷道图→动态水流状态→时间依赖安全图→第二突水点和信息延迟更新。

### 不合格递进

- 同一任务并列多种预测器，只选表现最好，却称为“综合模型”；
- 增加神经网络、群智能或聚类模块，但无法说明它补足了什么缺失关系；
- 第三问只增加变量，却宣称建立了完全新的理论模型；
- 改进模型改变了变量口径，导致前后结果不可比较。

## 2.3 核心特征三：多模型必须有接口

### 三种合法接口

| 接口 | 含义 | 代表论文 |
|---|---|---|
| 状态接口 | 前一模型输出系统状态，后一模型读取 | A242位置→碰撞；D037水到达时刻→路径可行性 |
| 参数接口 | 预测/估计模型输出参数，决策模型读取 | C050需求预测→利润优化；C126 VAR预测→定价补货 |
| 约束接口 | 机理模型输出可行域，优化在其中进行 | A196遮蔽判据→投放优化；B060干涉条件→厚度反演 |

### 模型接口检查表

| 子模型 | 输入 | 输出 | 输出进入哪里 | 不可替代作用 |
|---|---|---|---|---|
| 模型A |  |  |  |  |
| 模型B |  |  |  |  |

若某个模型无法填写“输出进入哪里”或“不可替代作用”，应考虑删除。

## 2.4 核心特征四：创新优先落在指标、约束和状态表达

### 有效创新实例

- **E176**：以“捕获动态信息达到阈值”为约束，以监测次数最少为目标，把经验建议改写为0-1选择。
- **A196**：用时间区间并集计算有效遮蔽，避免多烟幕重复时段简单相加。
- **C038**：用CVaR表达低收益尾部风险。
- **C050**：把单品数量和最小陈列量写入决策模型，而非事后筛选。
- **C132**：把达到4%检测阈值处理为时间到事件问题。
- **D037**：把巷道可通行性写成时间状态，而非固定边权。

### 复杂化风险实例

- **B477**：微元、贪心、随机森林和改进智能算法同时出现；若随机森林不能补充几何模型缺失的信息，就可能是冗余模块。
- **C228**：FP-Growth、LSTM、PSO、VIKOR、NSGA-II形成长链，真正主机制是价格弹性；模仿时应优先保留机制而非技术栈。
- **C132**：LMM、GPR、GA、LSTM、DeepHit、LightGBM和Optuna均有用途可能，但必须严格区分关系、时点和分类任务。

### 可直接模仿：五层模型设计法

| 层次 | 问题 | 产出 |
|---|---|---|
| 对象层 | 系统由谁组成 | 个体、节点、地块、镜面、车辆 |
| 状态层 | 当前状态如何描述 | 位置、水位、浓度、库存、缺陷状态 |
| 机制层 | 状态如何变化 | 几何、守恒、概率、回归、状态转移 |
| 决策层 | 哪些量可控制 | 路径、时点、价格、面积、投放参数 |
| 评价层 | 如何判断好坏 | 功率、概率、利润、风险、覆盖、时间 |

# 3　求解与算法

## 3.1 核心特征一：先用解析或确定性方法缩小问题

优秀论文通常遵循：

> **能解析就解析，能递推就递推，能精确就给精确基线；只有真正高维、非凸或随机的部分才交给启发式、仿真或机器学习。**

### 论文证据

- **A163**：非线性递推求把手位置，粗搜索确定临界区间，再用二分求碰撞时刻和最小螺距。
- **A242**：PDF第12页展示粗搜索—状态判定—精化流程；单参数临界值不直接使用PSO，多参数调头才用粒子群。
- **B060**：直接公式给厚度初值，再以Newton或非线性最小二乘联合反演。
- **D033**：低维概率积分和一维搜索，不使用高维智能算法。
- **B159**：简单生产决策完整枚举，多阶段才使用状态递推。

## 3.2 核心特征二：算法与模型结构一一对应

| 模型结构 | 优先算法 | 代表论文 |
|---|---|---|
| 单参数、近似单调临界值 | 二分、变步长、三分 | A163、A242、A165 |
| 链式位置或状态传播 | 递推、动态规划、事件驱动 | A016、D039、D037 |
| 低维概率积分 | 数值积分、一维优化 | D033 |
| 连续面积/光学积分 | 网格、Monte Carlo、光线追踪 | A092、A165 |
| 高维混合整数 | 求解器、GA/DE/PSO+修复 | C038、C234、B159 |
| 不确定性传播 | Monte Carlo、情景规划、贝叶斯更新 | D039、B195、C063 |
| 长时间序列 | SARIMA、VAR、小波、GM | E032、E176、C126 |
| 中小样本纵向/分类 | LMM、树模型、正则回归 | C023、E030 |
| 动态网络路径 | 时间依赖Dijkstra、事件驱动 | D037 |

## 3.3 核心特征三：算法流程必须完整

完整流程至少包括：

1. 输入和输出；
2. 初始化范围和初值来源；
3. 每次迭代计算什么；
4. 如何处理不可行解；
5. 如何保存当前最优解；
6. 停止条件；
7. 参数依据；
8. 复现信息。

### 约束处理证据

- C038/C234的种植方案必须在交叉、变异后修复轮作、豆类、地块和季次约束；只写标准遗传算法流程不能复现。
- C050单品决策必须保证27—33个单品和最小陈列量；候选方案若不满足，必须修复或判为不可行。
- A196多机多弹优化必须检查速度、弹间隔、数量和任务冲突。

## 3.4 核心特征四：参数和停止条件不能用默认值掩盖

### 参数合法来源

1. **题面给定**：速度、容量、阈值、置信水平；
2. **数学/统计准则**：AIC/BIC、轮廓系数、残差、数值容差；
3. **文献或实验**：种群规模、学习率、窗口长度、网络结构；
4. **敏感性验证**：关键参数变化后结论是否稳定。

### 停止条件模板

- 二分：区间宽度小于 `ε`；
- Newton/最小二乘：参数变化或残差小于 `ε`；
- GA/PSO/DE：最大代数与连续 `K` 代改善小于 `δ`；
- Monte Carlo：估计量或置信区间随样本量稳定；
- 机器学习：验证集早停，不以训练损失最低为准；
- 仿真：事件完成、状态不再变化或达到时间上限。

## 3.5 核心特征五：可复现性是算法的一部分

### 强复现实例

- **A196**：附录函数名如 `IntervalUnion.m`、`isOverwhelm.m` 与正文核心概念一致。
- **A242**：摘要直接说明结果写入 `result1.xlsx`、`result2.xlsx` 等文件。
- **C023**：第31页附代码，并提供交互网页作为应用输出。
- **E061**：附录可见固定 `random_state=42` 等实现参数。

### 最低复现清单

- 数据清洗脚本；
- 主程序与全部函数；
- 软件和包版本；
- 随机种子；
- 完整参数表；
- 输入输出字段说明；
- 结果文件与小问对应；
- 程序可直接生成论文核心表图。

# 4　结果质量

## 4.1 六级结果证据链

| 等级 | 证据 | 说明 |
|---|---|---|
| 1 | 直接作答 | 给出数值、区间、路线、策略或判断 |
| 2 | 约束核验 | 证明结果可执行 |
| 3 | 内部一致性 | 公式、图表、不同角度或小问一致 |
| 4 | 独立对照 | 与基线、实测或另一种方法比较 |
| 5 | 误差与敏感性 | 说明关键输入和数值精度影响 |
| 6 | 稳健性与边界 | 扰动后仍满足什么，并说明失效条件 |

只达到第1级只能证明“答了题”，不能证明结论可靠。

## 4.2 高可信结果实例

### B060：独立方法交叉验证

- 第1页报告直接法与Newton反演厚度约7.544 μm和7.295 μm；
- 第24页比较双光束与多光束拟合；
- 第27页单列“模型检验及合理性分析”；
- 不同入射角共享厚度参数，残差决定是否升级模型。

**可模仿点**：解析初值、数值反演、角度一致性和残差诊断构成独立证据链。

### A163/A242：临界值夹逼

- 先给粗搜索区间；
- 再给碰撞前与碰撞后状态；
- 二分至指定容差；
- 距离约束、路径连续性和区域约束可直接核验。

**可模仿点**：不要只报六位小数，要展示答案位于哪两个状态之间。

### B159：枚举核对策略

- 简单生产情形可完整枚举；
- 各成本项可回代期望利润；
- 多阶段动态规划与简单情形结果可相互核对。

### D037：动态可行性

- 检查节点流量守恒；
- 检查人员到达巷道时是否仍可通行；
- 第二突水点和信息延迟加入后，路线按新危险状态更新。

### E010：公平基线比较

PDF第10页同时比较K-means、DBSCAN和GMM，并使用轮廓系数选择，而非只展示一张聚类图。

## 4.3 敏感性分析必须改变现实关键参数

高价值敏感性变量：

- 定日镜网格密度、镜面规格；
- 测线重叠率、局部坡度和地形噪声；
- 蔬菜损耗率、价格弹性和需求误差；
- 生产缺陷率与成本；
- 种植价格、产量和CVaR置信水平；
- 烟幕起爆时刻、云团半径和时间步长；
- NIPT阈值、BMI边界和数据划分；
- 突水流量、人员速度和信息延迟。

只改变GA种群数，最多说明求解器稳定，不能证明决策结论稳健。

## 4.4 稳健性合格表述

```markdown
当参数【p】在【范围】内变化时，方案仍满足【硬约束】；核心指标变化不超过【比例】，且推荐决策【保持不变/仅在某边界切换】。当【失效条件】出现时，应重新估计【参数】或更换【模型】。
```

“模型稳定性强”而没有范围、指标和变化量，不构成证据。

## 4.5 结果解释必须回到机制

- A165用太阳视运动的东西对称性解释图6的空间分布；
- D033解释定位误差增大为何降低命中概率；
- C228用价格弹性解释价格和销量方向；
- D037用水到达时刻解释路线变化；
- E030用关键角度差异形成训练建议，但必须区分相关建议与已验证干预。

# 5　论文表达与图表风格

## 5.1 全文主线

推荐标准结构：

```markdown
摘要与关键词
1 问题重述
2 问题分析
3 模型假设
4 符号说明
5 问题一：模型—求解—结果—检验
6 问题二：新增条件—模型调整—结果—检验
7 问题三……
8 敏感性与稳健性
9 模型评价、适用范围与推广
参考文献
附录A：完整结果
附录B：程序
```

优秀论文通常让每问的模型、算法、结果和检验靠近，而不是先集中列完所有模型，十页后再统一给结果。

## 5.2 摘要的四要素

每问一段，包含：

> **任务 + 核心方法 + 关键结果 + 验证/优势。**

### 对比实例

- **C063第1页**：传统逐问摘要，内容完整但几乎占满整页，关键结论跳读困难。
- **D033第1页**：摘要嵌入较多公式，技术具体但评委阅读负担高。
- **B060第1页**：问题编号、核心方法和厚度结果适度加粗，扫描路径清晰。
- **C132第1页**：大量模型缩写、统计量和结果同时加粗，粗体失去层级。

### 摘要规则

- 每问2—3句；
- 只保留1—2个核心方法名；
- 最终数值带单位；
- 粗体占比建议不超过约10%—15%；
- 不放完整推导和大段参数；
- 摘要、正文、附录和结果文件数字完全一致。

## 5.3 公式表达

强论文的公式段包含四步：

1. 说明为何需要该关系；
2. 给公式和编号；
3. 解释每个新符号；
4. 说明该公式输出进入哪个后续模型。

### 公式模板

```markdown
为刻画【A】与【B】之间的【机制】，定义……。根据【定律/假设】，有

[公式]                                                     （x）

其中，……。式（x）的输出将作为【下一模型】的【输入/约束】。当……时，该式退化为……，与边界条件一致。
```

三行以上的纯代数变形移入附录；公式编号存在但正文从不回引，等于没有建立阅读链。

## 5.4 图表必须承担论证任务

代表性实例：

- **A165图6**：空间散点/热力图用于验证效率和功率分布的东西对称性；
- **A242第12页**：流程图表示粗搜索、状态判定和精化；
- **A242第20页**：盘入—调头—盘出轨迹图验证路径连接；
- **E010第10页**：三类聚类结果和轮廓系数用于选择方法；
- **E030第10页**：像素—实际尺度散点和三次拟合用于标定；
- **E030第20页**：训练前后关键角度表用于形成建议；
- **C132第20页**：BMI分组与风险关系用于解释决策边界；
- **C132第30页**：超参数表用于复现，但应同时给搜索范围和依据。

## 5.5 国赛图表视觉样式库

- 白底优先；

# 6　竞赛意识

## 6.1 第一页要证明“全部做完了”

优秀摘要让评委在一分钟内确认：

- 每个小问是否完成；
- 每问的核心方法；
- 最重要的数值、区间或策略；
- 本文的独特处理；
- 结果如何验证；
- 是否提交规定结果文件。

### 强实例

- **A242**：第1页同时给五问结果和 `result1.xlsx`、`result2.xlsx` 等文件；
- **A196**：用同一有效遮蔽指标逐层报告4.5873 s、6.9359 s、11.1259 s和21.0770 s；
- **D037**：摘要给逃生路线、时间和结果文件；
- **C023**：给5个BMI区间和推荐检测周数，并在摘要末显性列创新点。

## 6.2 创新应显性、具体、可指向正文证据

### C023式创新三点法

C023第1页摘要末明确写“本文创新性在于”，将重复测量处理、风险时点和异常判定/交互工具分开；第23页“模型评价”又明确写出数据依赖、泛化和未纳入因素等局限。

推荐格式：

```markdown
针对【题目难点】，本文在【指标/约束/状态/接口/交付】上采用【具体处理】；正文【章节/公式/图表】给出证据。
```

创新不超过3点。遗传算法、Python、Matlab、LSTM或Optuna本身不是创新。

## 6.3 详略必须围绕评委验证路径

正文优先保留：

> 核心问题理解 > 关键机制与公式 > 最终答案 > 验证与局限 > 通用算法介绍 > 中间输出。

完整坐标、七年种植矩阵、大段代码和重复参数表进入附录。

## 6.4 必须诚实限定结论

### 过度包装风险

- **A053**：摘要中调头曲线长度或最大速度出现疑似单位不一致；摘要单位错误会直接破坏可信度。
- **A178**：使用“模型准确完整”等绝对自评，但没有同步给比较对象。
- **B477/C228/C132/E218**：技术栈密集，容易把方法数量包装成创新强度。
- **C038/C234/A196**：启发式结果应称“较优解”或“在给定范围内最优”，不能无证明地称全局最优。
- **E030**：模型预测训练后可达到1.201 m，不等于已经完成真实训练实验；应写成预测目标或待验证建议。
- **C132/E218**：单次高准确率或奖励曲线不能证明稳定泛化，尤其要防止按记录随机划分导致个体泄漏。

## 6.5 参考文献与支撑材料

### 文献规则

- 物理、医学和工程参数引用权威来源；
- 算法引用原始论文或标准教材；
- 软件包注明版本；
- 正文引用与文末条目一一对应；
- 不以博客代替可获得的原始文献；
- 文献用于支持参数、假设和方法来源，而不是增加数量。

### 支撑材料规则

- README与运行顺序；
- 每个结果文件对应哪一问；
- 字段和单位说明；
- 主程序、函数、配置和随机种子；
- 能由程序直接生成正文核心表图；
- 不用代码或Excel截图代替可运行文件。

# 第二部分　优秀论文的共同风格与差异化风格

# 7　优秀论文的共同风格

37篇论文跨题型、年份和方法不同，但共同具有以下特征：

1. **一个核心机制贯穿全文**。A196用有效遮蔽区间，A242用把手位置与碰撞，B060用干涉相位，D037用水流状态。
2. **小问通过增加现实因素递进**。C038从确定到随机和风险，B060从双光束到多光束，C023从群体到个体。
3. **算法服务于结构**。临界值用二分，高维整数用GA/DE，动态图用Dijkstra，重复测量用LMM。
4. **摘要给具体结果**。数值、区间、路线、策略和结果文件在第一页可见。
5. **答案可执行**。镜场坐标、测线、补货表、种植矩阵、生产策略、检测周数和逃生路线均能转为行动。
6. **至少提供一种可信度证据**。残差、极限情形、独立方法、基线、敏感性或Monte Carlo。
7. **关键图表承担论证任务**。不是单纯美化，而是验证对称、临界、拟合、选择或路径可行性。
8. **正文与附录分工**。正文保留核心机制与答案，附录承担全量数据和程序。
9. **创新通常来自题目结构**。有效指标、现实约束、状态表达和模型接口比求解器名称更重要。
10. **成熟论文会说明局限**。C023第23页直接列缺点，比空泛“可进一步优化”更可信。

# 8　差异化风格与适用题型

## 8.1 机理几何型

- **代表**：A127、A165、A016/A163/A242、D033、A196、B060/B157、D037。
- **核心结构**：物理/几何/概率/守恒关系→解析或数值求解→边界/一致性验证。
- **适合题型**：运动学、光学、概率几何、路径、网络传播、测量反演。
- **优点**：解释强、可复算、外推有条件依据。
- **风险**：基础推导错误会影响全部结果；理想假设可能造成系统偏差。
- **必须有的证据**：示意图、边界情形、守恒/对称/相切检查、数值精度。

## 8.2 统计推断型

- **代表**：C126、E032/E176、C023、C132。
- **核心结构**：数据结构诊断→统计关系/时间序列/层级模型→区间或风险→决策。
- **适合题型**：医学、水文、经济、调查和纵向数据。
- **优点**：能表达显著性、区间和个体差异。
- **风险**：数据泄漏、样本不足、先验/分布敏感、相关性过度解释。
- **必须有的证据**：正确划分、残差、信息准则、置信区间、校准和稳定性。

## 8.3 运筹优化型

- **代表**：D039、B159/B195/B196、C038/C063/C094/C234、E176。
- **核心结构**：决策变量→目标函数→硬约束→确定性基线→随机/风险扩展。
- **适合题型**：排产、种植、补货、监测、资源配置和生产决策。
- **优点**：方案可执行，约束和目标清楚。
- **风险**：未来参数假设决定所谓最优；启发式可行性和稳定性不足。
- **必须有的证据**：逐条约束核验、小规模精确基线、情景比较和参数敏感性。

## 8.4 仿真与数据驱动型

- **代表**：B195、E010/E061/E218、C228、E030。
- **核心结构**：数据处理/事件仿真→预测或状态识别→策略→前后评价。
- **适合题型**：交通、复杂生产循环、视频、非线性预测和动态控制。
- **优点**：能处理高维非线性和复杂流程。
- **风险**：黑箱、参数多、复现压力大、对基线不公平。
- **必须有的证据**：数据划分、基线、重复运行、参数表、仿真假设和独立测试。

## 8.5 分层混合型

- **代表**：A196、C023、C132、D037、E010。
- **核心结构**：上层分配/分组/状态识别，下层优化连续参数或具体方案。
- **适合题型**：多对象协同、个体化决策、离散—连续混合、大规模任务。
- **优点**：降维，符合现实组织结构。
- **风险**：上层错误向下传播，层间接口不清。
- **必须有的证据**：层间输入输出、反馈或误差传播、联合与分层方案对照。

## 8.6 风格选择原则

- 有可信机理时，机理模型优先；机器学习用于补参或修正。
- 单参数临界问题优先二分/变步长，不直接上遗传算法。
- 高维整数规划先尝试求解器或小规模精确基线，再用启发式扩展。
- 小样本医学与人体数据优先层级模型、正则化和按个体验证。
- 多目标必须展示Pareto、权重敏感性或主要目标阈值，不能随意加权。
- 并非每道题都需要“基础+改进+综合”三套完全不同模型；统一机制的深化通常更强。

# 9　从读题到提交的十二步流程

## 第一步：建立任务矩阵

| 小问 | 对象 | 输入 | 输出 | 指标 | 硬约束 | 与前问关系 | 结果文件 |
|---|---|---|---|---|---|---|---|
| 1 |  |  |  |  |  |  |  |

完成后检查是否有对象层级、时间尺度或口径变化。

## 第二步：写一句核心机制

示例：

- A196：烟幕是否有效，取决于云团是否遮挡导弹—目标视线，目标是最大化遮蔽时间区间并集。
- B060：条纹周期由光程差决定，厚度可由相位关系反演，残差用于判断双光束假设是否失效。
- D037：逃生路径是否安全取决于人员到达某边时该边是否仍可通行。

一句话写不清，说明问题理解尚未稳定。

## 第三步：建立最小基础模型

只保留主要对象、状态和机制；给出可以独立运行的第一版结果。不要在基础模型未验证时加入多种算法。

## 第四步：列假设及偏差方向

| 假设 | 依据 | 删除的因素 | 可能偏差 | 失效场景 | 后续修正 |
|---|---|---|---|---|---|

假设不能只写“便于计算”。

## 第五步：建立模型接口

画出数据、状态、参数和约束如何流动；删除没有明确输出用途的模型。

## 第六步：按结构选择算法

先判断是否有解析、递推、单调、凸性、稀疏图或低维特征，再考虑启发式和机器学习。

## 第七步：先做小规模或简化验证

- 枚举可验证动态规划；
- 解析公式可验证数值迭代；
- 粗步长可定位二分区间；
- 简单基线可验证复杂模型是否真正增益。

## 第八步：写完整参数和停止条件

所有经验参数均标注来源；随机算法固定种子并重复运行。

## 第九步：建立结果证据链

每问至少完成：答案→硬约束→内部一致性→一种独立验证。关键问再做敏感性和稳健性。

## 第十步：先写结果段，再写摘要

摘要必须根据已经核对的正文结果写，不能在模型尚未稳定时提前包装亮点。

## 第十一步：整理附录和结果文件

程序、数据、结果文件和论文中的表图建立一一对应关系。

## 第十二步：按评委阅读路径终检

先只看标题和摘要，再只看各问结论，再看检验和附录；若无法快速确认完成度和可信度，继续修改。

# 10　常见错误与改进建议

| 常见错误 | 表现 | 为什么有问题 | 改进方式 | 相关实例 |
|---|---|---|---|---|
| 对象层级混乱 | 品类与单品混算 | 变量和约束口径不一致 | 建立对象层级表 | C050提供正例 |
| 小问彼此断裂 | 每问换一套模型 | 无统一主线 | 明确共享状态和接口 | A196、D037正例 |
| 算法名代替模型 | “建立遗传算法模型” | 求解器不是现实关系 | 先写变量、目标和约束 | C038/C234风险 |
| 为复杂而复杂 | 多模型并列 | 无不可替代作用 | 模型接口表，删除冗余 | B477、C228、C132 |
| 低维问题用群智能 | 单变量用GA | 不稳定且难复核 | 二分、三分、一维优化 | D033、A163正例 |
| 参数无依据 | 默认学习率、种群数 | 无法复现 | 文献、准则或预实验 | C132、E218风险 |
| 无停止条件 | “迭代至收敛” | 收敛不可检查 | 写容差、代数、早停 | A242正例 |
| 只报最好一次 | 随机算法单次结果 | 可能偶然 | 多次均值、标准差、最好值 | GA/PSO/DE通用 |
| 只给结果不解释 | 表后无分析 | 无法判断合理性 | 回到机制和约束解释 | A165图6正例 |
| 可行当作最优 | 满足约束即称最优 | 缺比较或证明 | 给基线、小规模精确解 | C094/C234风险 |
| 只调算法参数做敏感性 | 只改种群数 | 不能证明决策稳健 | 改现实关键参数 | C038、D037适用 |
| 数据泄漏 | 同一人的记录跨训练测试 | 指标虚高 | 按时间/个体/场景划分 | C132、E030风险 |
| 摘要技术栈堆砌 | 大量缩写和粗体 | 主贡献不可见 | 每问只留核心方法 | C228、C132 |
| 虚假精度 | 六位小数无现实意义 | 计算精度≠工程精度 | 按数据精度报告 | A242需限定 |
| 单位不一致 | 摘要与正文单位冲突 | 第一页直接失信 | 四重核对 | A053风险 |
| 自我评价代替证据 | “准确、鲁棒、优良” | 无可核验证据 | 写对比、误差和范围 | A178、E176风险 |
| 相关性写成因果 | 姿态相关即训练有效 | 结论过强 | 写预测建议并待实证 | E030风险 |
| 图表装饰化 | 3D、彩虹、过多颜色 | 精确读数困难 | 白底、少色、一图一问 | 图表库规则 |
| 大表挤正文 | 全部坐标和七年矩阵 | 主线被数据淹没 | 正文汇总、附录全量 | C038/C234 |
| 截图替代支撑文件 | Excel/终端截图 | 不可复现 | 提交结构化文件与程序 | D037需加强 |

# 结论

综合37篇论文，最值得模仿的不是某个固定模型，而是一种稳定的竞赛工作方式：

> **用最少但足够的模型抓住题目核心机制，用与结构匹配的算法完成求解，用独立证据和扰动分析界定结论可信范围，再把答案、亮点、验证、程序和局限组织成评委能够迅速复核的完整交付。**

优秀论文通常“看起来简单但证据密”，而不是“方法很多但关系松散”。真正的高级感来自统一口径、模型递进、算法克制、结果可核验、图表有任务、摘要有答案、附录能复现，以及对局限保持诚实。
