# 阶段一多路独立方案与盲评选优

## 目的

以八条互相隔离的推理路线作为最低配置扩大建模搜索空间，再由阶段一八个既有专业角色对全部方案进行盲评，选出最值得落地的主方案。题型复杂度、跨领域结构或风险分歧需要时动态增加方案 Agent 和专项评委，不设人为数量上限；不得让一个 Agent 批量伪装多份方案。

## 1. 统一输入与隔离

建立只读的 `proposal-input-packet`，仅含：

- 当前赛题、全部附件、原始数据和当年官方规则；
- 已核实的任务矩阵、对象口径、交付物和计算资源边界；
- 综合指南本阶段相关章节；
- 联网、外部资料、AI 使用和引用披露的允许范围。

先调用至少八个不同 `proposer_id` 的方案 Agent，基础编号 `P1`–`P8`。若题目包含多个相互独立的领域机制、分层混合结构、关键假设分叉、强非线性/离散难点或高风险合规问题，增加 `ADDITIONAL-PROPOSER-*`；每个新增 Agent 必须有明确探索方向，但仍独立完成全题方案，不得只负责一个碎片。尽量同时派发；并发槽不足时可分批运行，但必须在读取任何候选输出前派发本轮全部任务，并保持输入、提示和信息可见性一致。候选 Agent：

- 只能读取统一输入包，不能读取其他候选的草稿、检索词、文献或结论；
- 不能参与八席评分，也不能从评委处获得定向提示后改写对手方案；
- 必须保留自己的推理路线、失败分支和来源记录，不能只交算法清单。

## 2. 每个候选的三段工作

### A. 先独立思考

搜索文献前先封存 `pre-search-reasoning`：

- 逐问理解、核心机制和主要困难；
- 最小基础模型、候选改进和小问接口；
- 数学结构、预期算法、验证方式和最大风险；
- 哪些知识缺口需要文献回答。

不得先搜索历年同题答案再反推模型。封存后只允许补充带来源的新认识，不能覆盖原始思考痕迹。

### B. 再独立检索论文

仅在当年规则和用户授权允许时联网。围绕已登记的知识缺口独立检索，优先顺序为：

1. 与当前机制直接相关的顶级或领域公认高质量期刊/会议原始论文；
2. 奠基性方法论文、权威综述、标准、教材或官方技术资料；
3. 能提供参数、边界条件、误差分析或验证方法的可信领域研究。

“顶刊”不能只凭期刊名、影响因子或搜索排序判断。逐条核实题名、作者、年份、期刊/会议、DOI 或稳定链接、研究对象、适用前提、可迁移部分和不可迁移部分；搜索摘要、聚合页和二手解读只能用于定位原文，不能替代原始证据。无法访问全文或无法核实时明确标记，不得编造引用。

若规则禁止联网，则只使用允许的本地资料并记录限制；不能为满足本流程越权搜索。历史竞赛论文只能启发表达或方法候选，不能成为当前题目结论的证据。

### C. 融合为本题方案

建立“独立思考—文献机制—本题改造—验证证据”映射。只引入能解决当前痛点、满足数据与资源条件且可验证的部分；说明文献方法为何适用、改了什么、没有照搬什么。最终方案必须由本题对象、约束和接口重新推导，不能把论文方法名拼成技术堆栈。

## 3. 全部候选的统一交付

每个 `P*` 使用相同结构：

1. 逐问任务闭合与一句核心机制；
2. 文献证据表及来源核验状态；
3. 最小基础模型与手算、符号或微型实例检查；
4. 融合模型：变量、目标、约束和小问接口；
5. 算法匹配、资源预算和停止条件；
6. 独立验证、敏感性/边界、反例和消融计划；
7. 相对基础模型的真实增益、代价、风险、失效条件和被否决的替代路线；
8. 可编码性结论和仍缺失的证据。

候选必须覆盖全部官方小问。缺少关键题目、数据或规则时共同 `BLOCKED`；不能让多个 Agent 分别猜测缺失信息。

## 4. 阶段一八席盲评

将全部方案移除作者信息，随机映射为 `C1`–`Cn`（`n ≥ 8`）。至少调用：

`S1-JUDGE`、`S1-DOMAIN`、`S1-PROBLEM`、`S1-RIGOR`、
`S1-INNOVATION`、`S1-IDENTIFIABILITY`、`S1-SIMPLE`、`S1-REDTEAM`。

题型存在八席未覆盖的专业风险时增加 `ADDITIONAL-*` 评委；新增席必须对全部候选使用同一量表完成评分，不能只为某个偏好方案背书。

每位评委必须：

- 阅读全部候选和相同原始材料；
- 按自己在[评审量表](review-rubrics.md)中的五项标准，给每个候选五项 `0/5/10/15/20` 分和证据；
- 在封存前不看其他评委分数、排名或意见；
- 对全部方案使用同一尺度，不因写作华丽、模型复杂或“顶刊”标签额外加分；
- 单列引用真实性、题意错读、硬约束失败、不可执行和历史答案迁移等否决项。

## 5. 汇总与胜者

有否决项的候选先失去获胜资格。对其余候选计算：

`candidate_total = 所有选优评委各自五项分数之和`。只有基础八席时满分 800；动态增席后满分为 `100 × 选优评委数`，且每位评委必须评价全部候选。

总分最高者获胜。若并列，依次比较：

1. 所有评委中的最低单席总分更高者；
2. `S1-RIGOR` 与 `S1-SIMPLE` 合计更高者；
3. 对并列方案执行同一个最小可行性/区分性检查，证据更强者。

不得随机指定胜者，也不得在看到总分后修改评分。保存 `proposal-selection`：匿名映射、逐席逐项分数、证据、否决项、总分、排名、并列处理和唯一 `winner_id`。

选优分数只回答“全部候选中哪个最值得继续”，不等于阶段一 `PASS`，也不充当终审。将胜者还原为 `P*`，只据已封存证据完善为阶段一完整模型合同；未获胜方案保留为备选与风险参考，不得未经重新推导和验证就拼接进胜者。最终模型冻结后，必须由未参与方案编写、选优或修改的全新阶段一终审团评审；选优分数不能复用或冒充最终模型评分。终审以八个既有角色为最低配置，并按专项风险动态增加 `ADDITIONAL-*`。
